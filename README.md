# DSA Challenge

Data Structures & Algorithms challenges generated by the **dsa-challenge** skill.

Each challenge is a small, self-contained codebase where a "works in principle"
implementation uses the **wrong data structure** for the job, plus a test that
exposes the inefficiency and a benchmark. The goal is to implement the correct
DSA to fix it, then see before/after statistics.

## Structure

```
dsa-challenge/
└── <topic>/
    └── <n>/
        ├── README.md        # the challenge: problem, naive impl, what to fix
        ├── src/             # the (naive) codebase
        ├── test/            # the test suite (fails/times out on large inputs)
        └── benchmark/       # measures the naive cost
```

## Topics

- Hash maps / sets
- Stacks / queues
- Linked lists
- Trees / BST
- Heaps / priority queues
- Graphs
- Sorting
- Two-pointer / sliding window
- Tries
- Union-Find / Disjoint Set
- Dynamic programming

## Difficulty

- **easy** — full guidance (names the data structure + the fix)
- **intermediate** — recommendation only (names the data structure)
- **hard** — no hints ("Good luck!")

## Workflow

1. Ask the assistant to generate a challenge (language + difficulty + topic).
2. Pull the repo to your machine.
3. Implement the fix; run the tests.
4. Push / compare before-after stats.
